# How to run a Battle Royale

## Before the BR starts (15 minutes)

Head to the BR location:

- **City** → Maze Bank
- **Cayo** → Airport
- **Sandy** → Airstrip

Create an **F3** using `/events` and paste in the message from **F3 messages** in the Actions Team Discord.

**Important:** When creating the F3, make sure you are in **default world** — not in noclip.

Post **2 F3s**, **5 minutes apart**.

---

## Starting the BR

After the last F3:

1. Take everyone into the royale world using:
   ```
   /worldarea royale (radius)
   ```
2. Tell them the rules:
   - **Teaming is allowed** — but only with people on the **same panel**
   - **No cars allowed**
3. Give everyone about **5 minutes** to spread out across the city.
4. Start the royale:
   ```
   /startroyale
   ```
   Set the **zone size to 2000**.

---

## During the BR

From here, watch over the event in **noclip with walls on**.

If you can't use the required perms, **DM Barry** and he will sort them. For now, let someone who has perms grab the host role if needed.

---

## After the BR

1. Get the **IDs of the winners**.
2. **Log them on the spreadsheet**.
3. Let the **winning team kill all Actions team members** (end-of-event tradition).

---
