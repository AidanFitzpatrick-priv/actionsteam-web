# Example guide

This is a placeholder. Add new guides by creating markdown files in `web/content/guides/`.

Each file needs frontmatter at the top:

```md
---
title: Your guide title
description: Short summary shown on the guides list
updatedAt: 2026-07-05
---

Your content here in markdown.
```

The filename becomes the URL slug. For example, `my-guide.md` is available at `/guides/my-guide`.
